save_to_disk Audio Test (Mic Only)

This page captures microphone audio only, creates a base64 WebRTC offer, and applies a base64 answer from save_to_disk.go.

  1. Click Start Mic + Create Offer.
  2. Copy the generated offer (first textarea) into offer.txt.
  3. Run go run save_to_disk.go < offer.txt 2>&1 | grep -m1 '^eyJ' > answer.txt.
  4. Paste answer.txt into the second textarea and click Apply Answer.
  5. Speak for 20-60 seconds, then click Stop.
